# 赵云与阿斗 · 单机复刻版

一款手绘风文字合成塔防 PC 游戏：**征兵 → 拖字牌上棋盘 → 拼名成将 → 死守阿斗**。

> 依据 [downxia.com 的《赵云与阿斗》介绍页](https://www.downxia.com/downinfo/520940.html) 复现的非官方单机同人版，仅供学习与个人游玩。原作为手机游戏，本作没有使用其安装包或素材；美术、音效均为程序绘制与合成。
>
> 本目录与《字统三国》版本完全独立，互不覆盖。

![主菜单](shots/01_menu.png)

## 直接游玩

运行 **`dist/赵云与阿斗.exe`**（Windows 10/11 64 位，单文件，无需安装）。

- 首次运行如遇 SmartScreen，点「更多信息 → 仍要运行」。
- 存档：`%APPDATA%\ZhaoyunAdou\save.json`（设置里可清除）。
- 纯单机塔防，打开即玩，不消耗体力。

## 出征加载

点「开始游戏」后不再进入匹配页：赵云骑着马、带着阿斗从屏幕左侧跑到右侧，下方进度条走完即进入所选关卡；点击任意处可跳过。整个过程是纯单机演出，不联网。

## 核心玩法

1. **征兵**：花「馒头」清空兵营并重新抽满一批；价格仍按征兵价格计算。
2. **拖上棋盘**：把字牌拖到绿色格子；放上棋盘后仍可继续拖动。名字字牌单独放置只会「打瞌睡」，几乎没有战力。
3. **横向相邻成将**：把名字牌横向相邻摆放，凑成姓名就临时组成武将：
   - `黄 + 忠 = 黄忠`（两张牌仍各自独立）
   - `关 + 羽 = 关羽` / `关 + 兴 = 关兴`
   - `诸 + 葛 + 亮 = 诸葛亮`（需要三张相邻）
   - 成将后每张字牌仍可单独拖动：移开一个字就拆开，重新相邻又会成将
   - 两张牌不能成将时，把一张拖到另一张上会交换位置
4. **兵种升级**：把同名同级的兵种牌拖到另一张上，原地升级，最高五级；
   兵营里的兵种牌也能直接拖到另一张兵种牌上合成；腾出的空位保持原位，其他字牌不会向左挤。
   不同兵种之间、兵种与名字牌之间也可以拖拽换位。
5. **武将升级**：把武将姓名中包含的字拖到武将上：
   - 只拖入部分字：攻击小幅增益（每个字 +8%）
   - 集齐完整姓名：武将升级，属性大幅提高，最高 Lv5
   - 例：关羽先拖「关」只加攻，再拖「羽」升到 Lv2；升级后融合进度清零，可继续收集
6. **农民**：农民每 4 秒产出馒头，升级后产量更高；放在安全位置，是经济来源。
   开战前把农民放上棋盘，也会持续产馒头。
7. **守住阿斗**：贼兵沿褐色道路冲向右下角的阿斗，每漏一个掉一颗心；五颗心掉光即失败。守满十波获胜；第4、7波有小目，第10波是最终头目。

战斗中击杀得馒头（+1/个，贼将更多），每清一波额外奖励馒头；也可以「催战」提前开下一波换 5 馒头。

## 美术与交互

- **选字高亮**：选中营中或棋盘上的字牌，所有能与它合成的字牌都会亮起金框并标注「可合」。
- **武将立绘**：武将卡左侧是专属头像/兜帽，卡面颜色随定位变化；成将后两张字牌仍能分别拖动。
- **兵种图标**：刀、枪、骑、弓、盾、力、农各有独立的武器或农具小图。
- **地图细节**：巨鹿的营帐、长坂的破车、赤壁的火盆、虎牢的旗帜，加上路沿石、车辙、草丛、木牌与环境粒子。
- **攻击演出**：每名武将/兵种有独立弹道（偃月弧、突刺、箭矢、毒箭、符纸、扇箭、冲骑、盾击、重拳、锄击等），从卡牌直接飞向敌人并在敌人身上炸开命中特效。
- **技能演出**：青龙偃月、咆哮、七进七出、百步穿杨、八阵图等都有专属光环/文字/轨迹。

## 单体与群体伤害

所有武将和兵种都分为两类，图鉴、字牌库和战斗信息栏都会显示；技能和攻击特效已延长停留时间并加粗提亮：

- **个体伤害**：只打一个目标
- **群体伤害**：命中范围内多个目标

武器类型决定攻击演出：

- **刀**：关羽旋身挥动青龙偃月刀一圈；其他刀将横向刀光
- **矛**：张飞等直线穿刺，枪身穿过路径上的多个敌人
- **枪**：赵云等单点突刺；贯穿枪保留直线枪芒
- **弓**：黄忠等单发箭矢；孙尚香/袁绍等多目标连弩/扇射
- **骑**：马超/张辽冲锋枪骑，带尘土与拖影
- **剑**：曹操/刘备/孙权等剑斩与剑气
- **术**：诸葛亮/司马懿/周瑜等符纸、八卦、连锁术法
- **力/盾**：许褚/盾兵等震地冲击波
- **农**：锄击

## 地图差异

每张地图的逻辑格数、配色、环境粒子和敌军路线都不同；**格数少的地图会把格子拉大，铺满同一块棋盘区域**，不会缩成小图。

地块现在带高光/阴影切面，地图外框有厚度与边缘暗角，树、石、帐篷、军旗、火盆都有落地投影，画面更有层次。

## 难度与肉鸽军令

- 名字字牌基础概率从 45% 降到 **30%**；第一次征兵保底一张名字牌，之后不再保底
- 已有某姓名的一半时，另一个字的出现权重适度提高；蜀地补字权重更高，但不会高到必出
- 敌军数量约 **-32%**，但单个血量约为原来的 **1.86 倍**（本轮再厚 20%）、整体更强
- 每关 **10 波**：第 4、7 波各有一名小目，第 10 波是最终头目
- 开局馒头 50，征兵 32（每征一次 +4）；每波开战还会扣军粮（2+波数）；击杀与波次奖励也降低
- 武器背包可强化「将星」提高名字牌概率、「天运」提高优/神将权重
- 每守住 **2 波** 会出现一次 **军令三选一**，只在本局生效：
  - 厉兵（攻击）、疾战（攻速）、远谋（射程）
  - 招贤（名字牌概率）、轻赋（征兵便宜）、悬赏（击杀馒头）
  - 回春（回心）、军粮（馒头）、陷阵（敌军减速）、锋芒（暴击）
  - 战吼、狂战、神臂、富国、求贤、固本、破甲、血战
- 共 18 条军令，有纯增益，也有「血战」这种以心换攻的高风险选择

### 无尽增强

- 无尽模式每波提高敌人血量与强度；20 波后额外提高移速、护甲，并逐步增加同组敌人数量
- 数值有上限，避免后期完全无法处理

### 头目战法与武将动画

- 所有头目/小目的战法效果本轮再增强 **5%**：眩晕/减速持续更久，护盾更厚，回血更多，狂暴更快

- 被眩晕的我军头顶显示「晕」，停止攻击与技能
- 军令与刀币强化互相叠加，形成每局不同的成长路线
